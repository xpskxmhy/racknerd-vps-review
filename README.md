可执行的规则只有几条：

**电信、联通宽带，访客在国内** → 圣何塞优先，其次洛杉矶 DC-02。南方联通尤其适合圣何塞。

## 售后与几条只写在条款里的限制

工单响应是 RackNerd 口碑里比较硬的一项。一位长期用户记录三年多开了 7 个工单，全部在半小时内回复，有中文客服，可以发中文工单。第三方测评里还有“平均 10 分钟以内”的说法，两个数字不一致，按“半小时内”理解更保守。

下面几条是从官方知识库和服务条款里翻出来的，中文测评基本不提，但会影响你怎么用：

**换 IP**：官方帮助文档写明，VPS 客户在特定期限内申请更换 IP 免费（第三方资料普遍说是开通 72 小时内），超出期限后需要付费。IP 被墙属于偶发情况，可以在面板自助付费更换。

**IPv6**：不是所有机房都有。官方说明是洛杉矶和法国机房可申请最多 100 个免费 IPv6，下单后开工单申请，其他机房在逐步支持。如果你的项目依赖 IPv6，机房选择范围会被压缩到这两个。

**嵌套虚拟化**：服务条款明确禁止在 KVM VPS 里再跑虚拟机、VPS 服务、模拟器这类需要硬件虚拟化的东西，除非拿到书面许可。条款同时写明 Docker、Docker Compose、LXC/LXD、Kubernetes、K3s 这类容器化负载是允许的。想在里面套娃开小机的，直接买独立服务器。

**备份**：VPS 默认不含托管备份，数据完整性由用户自己负责。条款里写得很直接，别指望商家帮你留一份。

**管理范围**：这是非托管产品，软件环境、安全加固、故障排查都归你。工单能帮你解决平台层面的问题，不会帮你调 Nginx 配置。

## 常见问题

**能装 Windows 吗？**
促销 KVM 套餐官方列出的系统是 Linux 各发行版加自定义 ISO。需要 Windows 走单独的 Windows VPS 产品线，或者开工单问能不能挂自己的 ISO。

**1G 内存够跑 Docker 吗？**
够跑 Docker 本身和一两个轻量容器。官方对一键应用的建议是：n8n、Coolify 从 2GB 起比较舒服，AnythingLLM、Ollama、LibreChat、Hermes Agent 要 4GB 以上，OpenClaw 要 8GB。想在容器里跑大模型，1G 档不用考虑。

**支持支付宝吗？**
第三方中文资料普遍记录支持支付宝、微信支付、PayPal、信用卡和 USDT 等加密货币。官方知识库确认接受主流信用卡。付款后即时开通，几分钟内能 SSH 登录，不需要人工审核。

**需要另外买独立 IP 吗？**
不用，每个套餐自带 1 个独立 IPv4。

**会不会跑路？**
2019 年成立，早期被列进“跑路四大金刚”，这个说法这几年基本消失了。公司主体是特拉华州注册的 RackNerd LLC，办公地址在加州 Rancho Cucamonga，上过 Inc. 5000。这些是可查的事实，不构成对未来经营的保证。年付产品建议按年评估，不要一次买三年。
